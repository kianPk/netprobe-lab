# Security

These repositories are **educational demos and portfolio surfaces**, not production services.

- Do not deploy against untrusted networks without hardening, auth, and rate limits.
- Never paste real production secrets, keys, or PII into public demos or issue trackers.
- Honeypot, probe, and intel tools use **simulated or allowlisted** data by design.
- Report suspected abuse of live demos to the repository owner via GitHub Security Advisories or email listed in the profile README.

Use at your own risk in lab environments only.
